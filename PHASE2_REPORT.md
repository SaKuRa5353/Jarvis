## 2.1 Enhanced Fuzzy Correction

### Что сделано

**Файл:** `src/fuzzy.py`

| Компонент | Было | Стало |
|-----------|------|-------|
| `_VOSK_FIXES` | 3 записи | 16 записей |
| `KNOWN` (словарь) | ~40 слов | ~120 слов |

### Новые `_VOSK_FIXES`:
- **ВКонтакте:** `вэ ка`, `века`, `вэка` → `вк`
- **DeepSeek:** `дип сик`, `эдип сик`, `депсик`, `дикси`, `deep sick` → `дипсик`/`deepseek`
- **Громкость:** `тонкость`, `звукость` → `громкость`
- **Музыка:** `узыка`, `мызыка` → `музыка`
- **Терминал:** `консул`, `терминаты` → `консоль`/`терминал`
- **Google:** `за гугли`, `за гугле`, `загули`, `погугли` → `загугли`
- **Общие:** `открой то`, `запусти то` → `открой`/`запусти`

### Новые слова в `KNOWN`:
- Все модули: apps, system, web, sensors, weather
- Веб-сайты: moodle, расписание, почта, youtube, ютуб, музыка, vk, вконтакте, дипсик, deepseek
- Датчики: температура, процессор, видеокарта, кулер, радиатор, улицы, метео и др.
- Глаголы: открой, запусти, включи, выключи, перейди

### Тесты: ✅ 10/10

```
тонкость выше   → громкость выше    ✅
дип сик открой  → дипсик открой     ✅
консул открой   → консоль открой    ✅
загули что-то   → загугли что-то    ✅
музыка на ютубе → музыка включи    ✅ (контекст!)
вэ ка открой    → вк открой         ✅
```

## 2.3 Basic Metrics/Monitoring

### Что сделано

**Новый файл:** `src/metrics.py`

Компоненты:
- `MetricEntry` —統計 одной метрики (вызовы, среднее/мин/макс/всего время)
- `MetricsRegistry` — реестр всех метрик с методами `record()`, `get_report()`, `log_report()`, `reset()`
- `timed()` — декоратор для измерения времени выполнения функции
- `count_calls()` — декоратор для подсчёта вызовов (без замера времени)

### Интеграция `@timed` в ключевые функции:

| Файл | Функция | Метрика |
|------|---------|---------|
| `src/llm.py` | `JarvisLLM.ask()` | `llm.ask` |
| `src/tts.py` | `speak()` | `tts.speak` |
| `src/tts.py` | `_synthesize()` | `tts._synthesize` |
| `src/tts.py` | `_play_now()` | `tts._play_now` |
| `src/tts.py` | `_get_voice()` | `tts._get_voice` |
| `src/vad.py` | `SpeechRecorder.record()` | `vad.record` |
| `src/commands/__init__.py` | `plan_command()` | `commands.plan_command` |

### Вывод отчёта:
Метрики логируются при `KeyboardInterrupt` (Ctrl+C) в `src/assistant.py` → `run()`:

```

============================================================

  ------------------------------------------------------------
  llm.ask                          |     45 |   2500.0мс | ...
  tts.speak                        |     45 |    800.0мс | ...
  vad.record                       |     45 |   1200.0мс | ...
============================================================
```

### Тест метрик: ✅ Работает корректно
