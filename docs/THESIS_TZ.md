# ТЗ — техническое задание дипломной работы

Проект: **«Джарвис»** — офлайн-голосовой ассистент (Python 3.12, Vosk, Silero VAD,
Ollama/qwen3-jarvis, Silero TTS, sounddevice).

## 1. Предмет и цель

Разработка и математическое обоснование офлайн-конвейера автоматической обработки
голосовых команд: от акустического сигнала до обоснованного порционального действия.

## 2. Сквозная тема

**«Вероятностные методы и алгоритмы принятия решений в конвейере автоматической обработки голосовых команд офлайн-ассистента»**

Единый сюжет: **сигнал → признак → вероятность → решение с порогом → действие**.
Шесть звеньев конвейера, в каждом своя математика и свой порог, выведенный из данных.

## 3. Тема для заявления

**«Математическое и программное обеспечение подсистемы принятия решений офлайн-голосового ассистента»**
(название кафедры «математическое обеспечение» в ней буквально присутствует).

## 4. Восемь математических задач (декомпозиция конвейера)

### 1. VAD: скрытая марковская модель + алгоритм Витерби
- Где в коде: `src/silero_vad.py` (`SileroVAD.prob()`), `src/vad.py (SpeechRecorder, VAD_SPEECH_THRESHOLD = 0.5, VAD_SILENCE_THRESHOLD = 0.4)`.
- Модель: S = {тишина, речь}; наблюдения — апостериорные вероятности p_t ∈ [0,1] (VAD_FRAME = 512 при 16 кГц).
- Переходы A_ij = (N_ij + 1) / Σ_k (N_ik + 1); π_i; p_t|s ~ Beta(α_s, β_s) (ММП).
- Витерби: δ_t(i) = max_j [δ_{t−1}(j) · a_ji] · b_i(p_t); ψ_t(i) = argmax; q_T* = argmax δ_T(i); q_{t−1}* = ψ_t(q_t*).
- Сложность O(T·|S|²) = O(4T); при T ≈ 187 кадрах на 6 с (VAD_MAX_RECORD_SEC = 6).
- Гистерезис: s_t = 1 при p_t ≥ θ_on, s_t = 0 при p_t ≤ θ_off, иначе s_t = s_{t−1};
  Δθ = θ_on − θ_off выбирается из требования P(дребезг) ≤ ε.

### 2. Акустика: MFCC + DTW
- Окно Фурье: X_k = Σ x_n w_n e^{−2πikn/N}, w_n = 0.5(1 − cos(2πn/N)).
- Мел: m = 2595·log10(1 + f/700); фильтрбанк M = 26; дельты d_t.
- DTW: D(i,j) = d(x_i, y_j) + min{D(i−1,j), D(i,j−1), D(i−1,j−1)}; DTW = D(n,m).
- Окно Сако–Чурбуры |i−j| ≤ w → O(n·w) вместо O(n·m).

### 3. Wakeword: апостериор + критерий Неймана–Пирсона
- H1 = «обращение», H0 = «не обращение»; признак x = DTW-расстояние.
- P(H1|x) = f1(x)·π / (f1(x)·π + f0(x)·(1−π)); π = k/N = 20/112500 ≈ 1.8·10⁻⁴.
- Λ(x) = f1(x)/f0(x) ≥ η, η = (1−π)/π · C10/C01 ≈ 1.
- FAH ≤ 1 ⇒ α ≤ 8.9·10⁻⁶ — обратная задача измерения качества.

### 4. Нечёткое сопоставление: взвешенный Damerau–Levenshtein
- sim(a,b) = 1 − d(a,b)/max(|a|,|b|) ∈ [0,1].
- Итог: D(a,b) = λ·d(a,b) + (1−λ)·d_фон(a,b), λ ∈ [0,1]; порог по ROC/J(θ) = TPR − FPR.

### 5. Интенты: n-граммы + TF-IDF + наивный Байес
- char_ngrams n=2..4 с границами; TF-IDF; косинус; лапласово сглаживание; лог-форма;
  маржа P(top1) − P(top2) ≥ δ; действие только при P ≥ τ.

### 6. Эксперимент: WER, ROC, Wilcoxon, латентность
- WER/CER, TP/FP/PR/AUC, парный критерий Уилкоксона, перцентили Q50/Q95/Q99, протокол E1–E6.

### 7. Кэш TTS: закон Ципфа, IRM, E[T]
- h(N) ≈ ln N + γ; E[T] = h·T_wav + (1−h)·(T_synth + T_wav); оптимальный N*.

### 8. Реальное время: M/M/1, Liu–Layland, NLMS
- ρ = λ/μ < 1; E[T_first]; U_max = n(2^(1/n) − 1); M/D/∞; NLMS с условием сходимости.
