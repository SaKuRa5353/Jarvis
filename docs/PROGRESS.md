### Подтверждено

- `make ci` проходит: scoped ruff, mypy mathcore и pytest.
- Покрытие `src/mathcore` — 98%.
- Все четыре T9 self-test проходят без микрофона и Ollama.
- `pip install -r requirements.txt --dry-run` проходит в `.venv`.
- `wttr.in` доступен и возвращает JSON для Петрозаводска.
- Инструмент `calculate` через `execute_tool("calculate", {"expression": "sin(pi/2)"})` возвращает корректный результат `"1"` — верификация backend-части без задействования полного голосового маршрута.
- Пустой, пробельный, невалидный JSON, таймаут и ненулевой код возврата в запросе погоды обрабатываются как отказ.
- E2 (Vosk): 10/10 положительных срабатываний обнаружено, 0 ложных срабатываний в одной 30-минутной записи; долгосрочная вероятность ложной тревоги (FAH) не доказана как нулевая.
- Default-модель — `qwen2.5:3b`: она соответствует целевому CPU и не включает
  проблемный обязательный reasoning у `qwen3-jarvis`.
- Default-флаги: `FUZZY_ENGINE="wdl"`, `INTENT_ENABLED=True`,
  `VAD_DECODER="threshold"`, `WAKEWORD_MODE="text"`.

### Ограничения

- В репозитории отсутствуют размеченные пользовательские WAV-файлы (в Git не добавлены); пользовательские WAV хранятся локально, используется только TTS-кэш для автоматизированных тестов.
  Синтетические T9-пороги нельзя переносить в `config.py`.
- Нужны реальные STT-команды с golden-текстом, положительные/отрицательные
  записи wakeword и размеченные fuzzy/intent-примеры.
- Остались ручные `check_*.py`, проверки микрофона, Ollama, KDE и итоговая
  фиксация T12 после доступа к hardware/services.
- **E1 WER-разброс:** разница между `stt-e1-vosk-retry` (WER=0.9255) и
  `stt-e1-vosk-fixed` (WER=0.1277) совпадает с пользовательским изменением chunk_size с
  4000 на 2000 сэмплов в `scripts/measure_stt.py`; причинно-следственная связь не доказана. См. [reports/](reports/) для деталей.
- **Калькулятор:** `sin(pi/2)` через tool `calculate` возвращает `"1"` — подтверждено тестом `test_calculate_tool_sin_pi_over_2()`.
  Полевым путём ответ приходил как `0.707` из-за искажения STT («пи пополам» ≠ `pi/2`) + LLM отвечал из контекста, а не вызывая tool.
- **Погода (wttr.in):** добавлена защита от пустых/обрывочных ответов — если
  форматированный ответ содержит менее 3 слов, возвращается отказ «Не могу
  получить данные о погоде. Проверь интернет.».
